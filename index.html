ECCV 2026 Jun 17, 2026

Q-TriM: Question-Guided Tri-Modal Attention for Audio–Visual Question Answering

Q-TriM addresses information loss and error accumulation caused by deeply stacked multimodal attention in Audio-Visual Question Answering. Instead of sequentially fusing text, video, and audio through multiple attention layers, it performs shallow and parallel fusion using standard cross-attention together with a novel Tri-Modal Attention operator, where Query, Key, and Value can originate from different modalities.

A question-guided token filtering module uses dot-product scoring and a straight-through estimator to retain only question-relevant visual patches without introducing additional attention depth. Cross-attention and Tri-Modal Attention outputs are then combined through a question-aware modality mixture, allowing complementary information from text, video, and audio to contribute directly to answer reasoning.

Q-TriM was evaluated on MUSIC-AVQA, MUSIC-AVQA-R, and MUSIC-AVQA-v2.0. The model achieves strong state-of-the-art performance, including 70.89% overall accuracy on MUSIC-AVQA-R and 77.68% on MUSIC-AVQA, demonstrating effective multimodal fusion, robustness, and improved generalization to challenging and out-of-distribution audio-visual questions.

Authors: SungHun Kim, Seungjun Baek*

BAT-Transformer: 멀티모달 감정인식을 위한 오디오-텍스트-생리학적 신호 혼합 모델

본 연구는 대화에서 나타나는 발화자의 물리적, 생리학적 정보를 통해 긍부정도를 분류하는 것을 목표로 한다. 이에 텍스트, 오디오, 바이오 데이터 (손목피부온도, 피부전도도) 데이터로 학습한 트랜스포머 기반의 멀티모달 감정인식 모델인 BAT-Transformer(Bio-Audio-Text Transformer)를 제안한다. 텍스트와 오디오 데이터에 crossmodal attention을 적용하고 생체 신호 데이터끼리 concat함으로써 효율적으로 각 모달리티의 정보를 반영하여 모델을 학습했다. 실험 결과, BAT-Transformer가 유니모달 트랜스포머 모델들에 비해 더 좋은 성능을 보였다.

Authors: 국주현, 이영아, 강효은, 표솔빈, 고나경, 김성훈, 윤세휘, 김철연

SeqGAN을 활용한 멜로디 기반 가사 생성

본 연구에서는 SeqGAN을 기반으로 한 멜로디 기반의 가사 생성 방법을 제안한다. 노래와 그에 해당하는 가사가 한 쌍인 데이터를 직접 수집한 뒤, 멜로디의 정보를 잘 반영하기 위해 여러 단계의 feature 추출을 진행하였고, 그에 맞는 가사를 잘 생성하기 위해 SeqGAN 모델 구조를 사용하였다. 기존 가사와 생성된 가사의 감정을 분석한 결과, 82%의 일치율을 보였다. 이는 기존 가사가 멜로디를 잘 반영해 비슷한 감성의 가사를 잘 생성하였음을 의미한다.

Authors: 국주현, 강효은, 고나경, 김성훈, 김상윤, 이정우, 현승현, 홍종현, 김철연
